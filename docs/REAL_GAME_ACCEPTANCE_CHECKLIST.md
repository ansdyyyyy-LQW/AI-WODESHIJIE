# Minecraft 实机最终验收清单

该清单必须在 Windows + Minecraft 1.20.1 Forge + TLM 1.5.3 的真实世界中执行。自动 CI 不能替代此项。

## A. 非程序员启动
- 双击 EXE，无终端窗口。
- 向导检测实例、TLM、Bridge。
- 两套 API 可测试并在重启后继续使用。
- GUI 发现并绑定女仆，无需 UUID。

## B. Day 1 自主生存
- 不给人工任务，AI 连续提出多个 Goal。
- 木材、工具、食物、石头、铁、熔炼、装备、住所、储存由真实女仆完成。

## C. 身体和恢复
- 移动、挖掘、放置、合成、容器、战斗都由女仆执行并消耗真实资源。
- 不可达、目标消失、背包满、短时 API 失败不会永久死循环。
- 断开 Agent 后女仆安全停止。

## D. 丧尸战略
- 系统只提供数量、方向、伤害、破坏等事实。
- AI 自己提出至少一种防御调整，不调用预制陷阱函数。

## E. Memory / Skill
- 记住重要地点和资源；重复任务复用 Skill；重启后关键状态恢复。

## F. R&D
- 小额预算模拟第 5 日；Runtime/R&D 分账；生成 Handoff；不自动安装 Mod。

## G. 建筑
- 中型 Blueprint 计算材料；缺材料转资源 Goal；真实施工；中断后继续。

每项记录：日期、版本、存档、操作步骤、预期、实际、日志路径、视频时间点、PASS/FAIL。
